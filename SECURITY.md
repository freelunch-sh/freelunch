# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this
repository. Please don't open a public issue for one.
If that option is not there, open an issue that says only that you have a security report (no details) and the maintainer will arrange a private way to send it.

In scope: the CLI (`bin/freelunch`), the workflows it generates, the host scripts it runs over
SSH, and the state encryption. Out of scope: a provider's own service.

freelunch is maintained by one person, best effort, with no SLA. Never paste a token, key or
state file into an issue; if you did, revoke it first.
