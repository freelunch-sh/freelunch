## What's free

A **Free** cluster (formerly M0): **512 MB** of storage, 500 connections, 100 operations a second,
10 GB in and 10 GB out per rolling 7 days, **one per project**. Atlas pauses it after **30 days
with no connections**; you can resume it. A per-organisation cap on free clusters is **unverified**
(the docs list none). See the [limits page](https://www.mongodb.com/docs/atlas/reference/free-shared-limitations/).
Flex clusters (5 GB) are a paid, usage-based tier and are not used here.

Because of the one-per-project rule, each entry in `databases` gets its own Atlas project. The
cluster is always `M0` on the `TENANT` provider, so it can't bill. The stack checks the cloud
(AWS, GCP or AZURE) and a count of 5 clusters (a conservative figure of ours, not an Atlas
limit); `acknowledge_billable_resources = true` lifts both.

## API key

Make an API key in Atlas (Organization > Access Manager > API Keys, role Organization Project
Creator) and put it in `.freelunch/.env`:

```bash
MONGODB_ATLAS_PUBLIC_KEY=...
MONGODB_ATLAS_PRIVATE_KEY=...
```

Set `org_id` (Organization ID) in `terraform.tfvars`.

## Usage

```bash
freelunch init mongodb-atlas
cp .freelunch/mongodb-atlas/terraform.tfvars.example .freelunch/mongodb-atlas/terraform.tfvars
freelunch apply mongodb-atlas
freelunch output mongodb-atlas -json database_credentials   # { "mongodb-atlas-main": { password, url } }
```

Each entry makes a project, a cluster, a database user (random password, `readWrite` on the
database) and an IP access-list entry (`allowed_cidr`, default `0.0.0.0/0`: narrow it). Outputs
follow the [database contract](../../docs/architecture.md#database-contract): engine `mongodb`,
host from the cluster's `standard_srv` string, `url` is `mongodb+srv://...`.

## Caveats

- The password is generated by Terraform and kept in the state, so keep the state private.
- `0.0.0.0/0` is the default access list because free clusters have no private endpoints.
- Nothing here has run against a real account: the tests plan against a mocked API.
