# Provider template

Copy this folder to `providers/<name>/` to add a provider. Until the provider is implemented,
`bin/freelunch catalog` generates its README from `provider.yaml`. Once you write a README by
hand (remove the "Generated by" first line), the catalog leaves it alone.

Expected layout once implemented:

```
providers/<name>/
├── README.md              what's free, prerequisites, auth, layouts, caveats
├── provider.yaml          metadata (+ `limits:` for host providers)
├── modules/
│   └── <module>/          main.tf, variables.tf, outputs.tf, versions.tf, README.md, tests/
├── stack/                 root module: providers.tf, main.tf, variables.tf, outputs.tf,
│                          versions.tf, terraform.tfvars.example, tests/
└── scripts/               optional provider-specific helpers
```

The full checklist is in [docs/adding-a-provider.md](../../docs/adding-a-provider.md).
