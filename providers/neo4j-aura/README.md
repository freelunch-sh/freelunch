## What's free

AuraDB Free: one database with **200,000 nodes**, **400,000 relationships** and **1 GB** storage,
on-demand backups only (one at a time). It pauses by itself after 72 hours without activity, can't
be paused by hand, and is deleted, unrecoverably, after 30 days paused (an older blog post says 90;
the docs say 30). See [pricing](https://neo4j.com/pricing/) and the
[quotas](https://neo4j.com/docs/aura/classic/platform/quotas-and-limits/).

The stack always makes `type = "free-db"`, `memory = "1GB"`, and checks the instance count (1).
Unverified: that Free is limited to one instance per account, which regions Free offers (the
default is `gcp` / `us-central1`), and that the Labs provider can create a Free instance in
practice. Its schema lists `free-db` as a valid type, nothing more.

## API credentials

Make credentials in the Aura console (Account settings > API credentials) and put them in
`.freelunch/.env`:

```bash
AURA_CLIENT_ID=...
AURA_CLIENT_SECRET=...
```

You also need the Aura project (tenant) id as `project_id`.

## Usage

```bash
freelunch init neo4j-aura
cp .freelunch/neo4j-aura/terraform.tfvars.example .freelunch/neo4j-aura/terraform.tfvars
freelunch apply neo4j-aura
freelunch output neo4j-aura -json database_credentials   # { "neo4j-aura-main": { password, url } }
```

The stack outputs the [database contract](../../docs/architecture.md#database-contract): engine
`neo4j`, Bolt port 7687, database `neo4j`, user from the instance, behavior `pauses`.

## Caveats

- `url` is the plain `neo4j+s://<id>.databases.neo4j.io` address, without the login: Bolt drivers
  take user and password separately.
- The password is generated by Aura and kept in the state, so keep the state private.
- Nothing here has run against a real account: the tests plan against a mocked API.
