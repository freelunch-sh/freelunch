## What's free

CockroachDB Basic includes **$15 of usage a month**, equal to **50M request units and 10 GiB of
storage**, across all clusters in the organisation. A payment method must be on file; you are
charged only above the allowance. Contract customers are not eligible. New organisations also get
a 30-day, $400 trial (no card for Standard). Number of clusters is **unverified**. See the
[docs](https://docs.cockroachlabs.com/docs/cockroachcloud/free-trial); the pricing page itself
no longer lists a free plan.

The stack sets each cluster's `request_unit_limit` and `storage_mib_limit` to the allowance and
checks that the totals across clusters stay within it; more needs `acknowledge_billable_resources
= true`.

## API key

Create a service account and an API key in the Cloud console (Access Management) and put it in
`.freelunch/.env`:

```bash
COCKROACH_API_KEY=...
```

## Usage

```bash
freelunch init cockroachdb
cp .freelunch/cockroachdb/terraform.tfvars.example .freelunch/cockroachdb/terraform.tfvars
freelunch apply cockroachdb
freelunch output cockroachdb -json database_credentials   # { "cockroachdb-main": { password, url } }
```

Each entry makes a Basic cluster and a SQL user (random password). Outputs follow the
[database contract](../../docs/architecture.md#database-contract): engine `postgres`, port 26257,
host from `regions[0].sql_dns`, `url` is `postgresql://...?sslmode=verify-full`. Clusters have an
IP allowlist managed in the console.

## Caveats

- The password is generated by Terraform and kept in the state, so keep the state private.
- The provider deprecates `cockroach_sql_user.password` in favour of write-only `password_wo`, which
  needs OpenTofu 1.11+; this stack uses `password` and shows a warning.
- Idle behaviour is listed as `scale-to-zero` (Basic is serverless); unverified against the docs.
- Nothing here has run against a real account: the tests plan against a mocked API. The mock can't
  supply `sql_dns`, so tests don't check the host.
