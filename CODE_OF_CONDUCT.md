# Code of conduct

Be kind, assume good faith, and keep to the work. Harassment, personal attacks and
discrimination are not welcome here.

Report a problem by opening a private security advisory on this repository (Security → Report
a vulnerability) and saying it is a conduct report, or by contacting the maintainer through the
address on their GitHub profile. The maintainer may edit or remove comments, and block
people who do not follow this.

This is a short version in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
